Read on this machine; names, IBANs, transfer texts and card merchants are dropped as the file is read.

Ten agents read every company; each scores one side of it, such as valuation, shareholders or momentum. The ones set to Decides make the owner score, from -100 to +100. Timing agents only say when to buy. Nothing changes until you save.

Owner score weights i

These agents decide the score. Share is each agent's weight divided by the total: it is the agent's say in the score. Agents with low confidence count less (see the confidence floor). The tick switches an agent on or off everywhere.

Owner score levels

The entry and exit levels turn the owner score into actions in the portfolio review and the backtest. The strong levels only group scores in the backtest tables and raise a watchlist alert when a score crosses them.

Both scores

How much a low-confidence agent still counts. At 40%, an agent with no confidence keeps 40% of its weight. Applies to the owner score and to entry timing.

Entry timing weights

No vote: they only time an entry. A second score on when to buy, never on whether. The default weights are the same in every regime, because separate profiles added nothing in the tests. i

Entry timing levels

The score backtest starts its entry and exit fields at the entry and exit levels here. All four levels group results in its calibration table; nothing in the analysis uses them.

Roles and display order

Which agents decide, time or only inform. The order only changes how the analysis is listed. Decides: counts toward the owner score. Timing: when and how much, no vote. Informative: shown, never scored. i
